# 異世界探偵録 ～ナーロッパの事件簿～

逆転裁判の探偵パートをベースにしたブラウザアドベンチャーゲーム。

異世界に転移した男子高校生が、独自の法律や魔法を理解しながら街の事件を解決し、探偵業を軌道に乗せていく物語。

## プレイ

GitHub Pages: https://yamara-mh.github.io/mystery20260511/

## 技術スタック

- **フロントエンド**: React 19 + TypeScript
- **レンダリング**: Canvas API (背景・キャラクター・エフェクト描画)
- **状態管理**: Zustand
- **国際化**: i18next + react-i18next
- **ビルド**: Vite
- **デプロイ**: GitHub Pages (GitHub Actions)

## ゲームシステム

### 探索パート
- **調査**: カーソルを動かして画面を調べる
- **会話**: その場にいる人物と会話する
- **提示**: 証拠品・情報を人物に提示する
- **移動**: 別の場所へ移動する
- **整理**: 集めた証拠・情報を組み合わせて推理する
- **推理**: 調査中に持ち物から証拠を選んで調べる

### 議論パート
- **証言**: 証人の証言を聞く
- **詳しく (ゆさぶる)**: 証言について詳しく聞く
- **提示 (つきつける)**: 矛盾する証拠を突きつける

### その他
- **持ち物**: 証拠品・人物・情報の一覧表示
- **セーブ/ロード**: ローカルストレージによるセーブ管理 (10スロット)
- **設定**: BGM/SE音量、テキスト速度の調整

## シナリオシステム

シナリオデータはJSON形式で管理し、TSV形式への相互変換に対応。
スプレッドシートでの編集が可能。

逆転裁判3に存在する演出を再現するコマンド体系:
- テキスト表示 (タイプライター効果)
- キャラクター表示/非表示/移動
- 背景切替 (各種トランジション)
- 画面効果 (シェイク、フラッシュ、フェード、ティント)
- 天候効果 (雨、雪、霧)
- 「異議あり！」「待った！」「くらえ！」演出
- フラグ管理・条件分岐
- 証拠品/人物/情報の追加・更新・削除

## 開発

```bash
npm install
npm run dev     # 開発サーバー起動
npm run build   # プロダクションビルド
npm run lint    # ESLint実行
```
